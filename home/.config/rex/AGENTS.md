# REX CONFIG

Lua 5.1 config for the Rex multiplexer.
Stowed to `~/.config/rex/`. Same layout as the nvim config: `init.lua` only
bootstraps; everything lives in `dmmulroy/`.

## STRUCTURE

```
rex/
├── init.lua                  # require("dmmulroy") only
├── dmmulroy/
│   ├── init.lua              # ordered requires (actions before keymaps)
│   ├── keymaps.lua           # every C-; prefix bind
│   ├── close_pane_or_tab.lua # last pane closes the tab
│   ├── resize_mode.lua       # resize/* mode binds
│   ├── smart_splits.lua      # ctrl+h/j/k/l, Neovim-aware (pairs with nvim smart-splits.lua)
│   ├── import_theme.lua      # import_catppuccin_macchiato action
│   └── twitch_chat/          # init.lua (palette action), shared.lua, follow.lua (`rex do` script)
│                             #   panes run twitch-lua, the rock `dot` installs into
│                             #   ~/.local/share/rex/rocks (TWITCH_LUA_DIR: a checkout instead;
│                             #   TWITCH_CHAT_BACKEND in shared.lua; "twt" switches back)
├── themes/                   # Catppuccin Macchiato theme for the app
├── macos-defaults.conf       # app settings (font, Option key, tabs); `dot update` writes them
└── ssh_config                # generated by `rex terminfo setup` (gitignored)
```

## REFERENCE

- Full Lua reference: https://www.superlogical.com/rex/docs/reference/lua
- Docs index: https://www.superlogical.com/rex/docs/llms.txt
- Superlogical MCP, available through Executor (`mcp__executor`): run
  `search({ query: "superlogical" })` to get the tool paths. Tools:
  `superlogical.search_docs` (start here), `read_doc`, `list_docs`,
  `search_changelog` / `read_changelog`, `search_feedback` / `get_feedback`.
- Local CLI: `rex keymap` (resolved binds + source file:line),
  `rex client ls && rex -C <label> actions` (bindable actions),
  `rex api list` / `rex api describe <method>` (Lua `rex.session.*` calls).

## CONVENTIONS

- `require` resolves from this folder: `require("dmmulroy.keymaps")` loads
  `dmmulroy/keymaps.lua`, and `require("dmmulroy")` loads `dmmulroy/init.lua`.
- `rex do` scripts resolve `require` from the script's own folder, so
  `twitch_chat/follow.lua` loads `require("shared")`, not the dotted path.
- Custom actions are defined in their own file; `keymaps.lua` binds them by name.
  Require them before `keymaps.lua`.
- Prefix is `ctrl+;>` (`local P` in `keymaps.lua`).

## AFTER EDITING

Rex does not watch these files:

```bash
rex config check && rex config reload && rex keymap
```

`dot update` runs check + reload after re-stowing.

## ANTI-PATTERNS

- Putting config back into the root `init.lua`
- Binding a custom action before its file is required
- Dotted `require` paths inside `rex do` scripts
- App settings (fonts, theme, tabs) in Lua; they belong in `macos-defaults.conf`
